# AI Collaboration — BlackHub Barber

Esta pasta centraliza o contexto colaborativo entre o desenvolvedor e o agente de IA.

## Quando usar cada arquivo

| Arquivo | Uso |
|---------|-----|
| `duvidas.md` | Bloqueios reais, ambiguidades importantes, decisões críticas |
| `sugestoes.md` | Melhorias percebidas, refatorações, oportunidades de arquitetura |
| `decisoes.md` | Decisões técnicas tomadas e seus motivos |
| `proxima-sessao.md` | Estado de continuidade entre sessões de trabalho |

## O que NÃO registrar

- Pensamentos triviais ou logs de execução comum
- Comentários sem consequência
- Perguntas desnecessárias
- Sugestões cosméticas sem impacto

## Como manter limpo

- Registrar apenas o que realmente precisa ficar documentado
- Atualizar status das dúvidas quando resolvidas
- Mover decisões finalizadas para `decisoes.md`
- Atualizar `proxima-sessao.md` ao fim de cada tarefa relevante
