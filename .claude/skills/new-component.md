# Novo Componente

1. Verificar se ja existe componente similar em `src/components/`
2. Criar `src/components/{ComponentName}.tsx`
3. Verificar: `npm run lint` passa

Regras:
- TypeScript strict com interface de props
- Design System: Navy #1A1A2E + Gold #C4A35A
- Mobile-first com breakpoints responsivos
- Framer Motion so quando agrega valor real
